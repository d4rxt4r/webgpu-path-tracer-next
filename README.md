# WebGPU Path Tracer Next

Браузерный рендерер на TypeScript и WGSL: RGB и спектральный path tracing (PT), progressive photon mapping (SPPM), software BVH и редактор демонстрационной сцены.

## Запуск

Требуются Node.js 22.12+ и Chrome/Edge с WebGPU и аппаратным ускорением.

```sh
npm ci
npm run dev
```

Откройте адрес Vite. `npm run build` подготавливает модели, проверяет TypeScript и создаёт `dist/`; `npm run preview` запускает просмотр сборки. Для публикации нужен статический HTTPS-хостинг.

## Возможности и ограничения

По умолчанию: Suzanne high poly, диэлектрик, Quality spectral SPPM, глубина 32, 16 384 фотонных пути за итерацию, пакет 1024, начальный радиус 0,03 м, пиксельный бюджет 640×480 и память 192 MiB. `/?scene=control` открывает отдельную контрольную сцену со сферой и RGB PT.

Доступны Cornell/Open, площадной свет и постоянное или HDR-окружение. Встроены Suzanne high poly, Suzanne, Rastagotchi, Happy Buddha и сфера. Локальный OBJ переносит геометрию и нормали; доступны ремонт отверстий и ориентации оболочек. MTL и UV-текстуры не поддерживаются. Ремонт не гарантирует отсутствие самопересечений.

Материалы: диффузный с цветом и шероховатостью, диэлектрик с независимыми следами износа, физический металл и «Свой цвет», пластик, отражающий самосветящийся объект, процедурные мрамор и лава. [Описание материалов](docs/materials.md) содержит defaults, спектральные приближения и ограничения экспорта. Камера поддерживает фокус на цели, ручной и выбранный по точке, круглую и многоугольную апертуру.

Денойзеры: à-trous, bilateral и spatial NLM. NLM применяется на паузе или явно; продолжение накопления возвращает оригинал до следующего применения. Стекло по умолчанию без фильтра. Денойз, экспозиция и tone mapping не меняют raw-накопление. PNG сохраняет отображаемый кадр, включая включённый разделитель; PFM — линейный RGB; JSON — настройки и метаданные. Ссылки сохраняют скрытые группы, но не передают локальные OBJ/HDR.

Разрешение задаёт пиксельный бюджет с учётом viewport, DPR, памяти и лимитов устройства. Максимальный пресет — 4K. Ползунок памяти заканчивается на 4096 MiB; числовой ввод допускает больше в пределах безопасного расчёта байтов. Большой бюджет не означает такую аллокацию и не гарантирует ускорение. Яркость должна помещаться в конечные GPU-параметры. Поддерживаются до 32 активных сред; совпадающие границы и самопересекающиеся оболочки не поддерживаются.

## Проверки

```sh
npm test
npm exec tsc -- --noEmit
npm exec vite -- build
npm run test:browser
```

Прямой запуск Vite обходит перегенерацию manifest моделей. Playwright использует установленный Chrome, один worker и свой dev-сервер. [Проверки](docs/verification.md) отделяют CPU/сборку от выполненных GPU/browser-сценариев; полный браузерный набор не подтверждён. [Дорожная карта](docs/development-roadmap.md) содержит оставшиеся задачи и исторические проблемы для повторной проверки.

Диагностика: `npm run benchmark`, `npm run validate:runtime`, `npm run validate:spectral-sppm`, `npm run validate:quality -- --pbrt <путь-к-PBRT-v4>`. Результаты сохраняются в игнорируемую папку `artifacts/validation/`; повторное использование эталонов описано в документе проверок.
