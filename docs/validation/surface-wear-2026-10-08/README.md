# Настройки износа, 2026-10-08

Три независимых эффекта с чекбоксами, сохраняемыми скрытыми параметрами, относительным/физическим масштабом и собственным seed. Подробные параметры описаны в подсказках интерфейса. Старый формат материала и прежние ссылки поддерживаются; новый экспорт использует `surfaceWear.version = 2`.

PT, SPPM и направляющие денойзера специализируются по активности эффектов. Неиспользуемые блоки удаляются до компиляции; полностью чистый вариант содержит только функции возврата исходного материала/нормали. Материалы без активных следов выходят до процедурных вычислений даже в смешанной сцене. Кэш хранит два готовых варианта на семью pipeline и разделяет незавершённую компиляцию. Буферы SPPM и текстуры денойзера при переключении варианта переиспользуются.

## Проверки

- CPU: миграция legacy, глубокое копирование, сохранение выключенных параметров, границы значений, packing, маски, удаление кода, кэш и защита от устаревшей компиляции. Физическая метрика `sqrt(AᵀA)` проверена по длинам и симметрии при shear, отражении и поворотах.
- [GPU grid](gpu-grid.json): Intel gen-12lp, подключённый Chrome, сетка 128×128, 21 случай. Нет неконечных нормалей/BSDF, отклонение длины нормали ≤ 1e-5; sampling/evaluation PDF совпадают. Изменение seed и масштаба каждого эффекта меняет рисунок, seed неактивных эффектов даёт точный нулевой diff. Варианты с масками 0/1/2/4 совпадают с общим шейдером побитово для соответствующих материалов.
- Физический режим: при увеличении объекта в 1,7 раза, повороте и переносе совпадающие физические точки дают максимальный diff roughness 2,57e-6 и normal 4,67e-7. Относительный режим сохраняет рисунок при преобразовании объекта: roughness ≤ 1,58e-5, normal ≤ 4,86e-7.
- Browser: тонкое/объёмное стекло в RGB и spectral SPPM; панели, отключение с сохранением, средняя кнопка для сброса, независимый новый seed, физический числовой размер, JSON, round-trip ссылки и пресеты. Регрессия денойзеров проверяет raw accumulation, NLM на паузе и старые ссылки стекла.
- Подключённый Chrome: spectral SPPM + все три эффекта + денойз по поверхности, 129×147, depth 8, 1024 photons/iteration, batch 1024, 4 iterations. Seeds 11/22/33; масштабы 2,5 model / 0,3 scene / 1,5 model; 8 отпечатков. Ошибок нет, горизонтального переполнения панели нет. [Снимок интерфейса](editor-sppm-spectral.jpg) фиксирует раннее накопление, а не сходимость изображения.

## Локальное измерение GPU

Один проход сетки 16384 точек, усреднение четырёх dispatch внутри timestamp-интервала. Это микротест поверхности и BSDF, а не время кадра или универсальная оценка скорости.

| Вариант | GPU, мс |
| --- | ---: |
| Общий шейдер, нулевой износ | 0,147456 |
| Общий шейдер, все эффекты по 0,5 | 0,393216 |
| Чистый специализированный шейдер | 0,032768 |

Замеры квантованы таймером текущего адаптера; один локальный запуск не заменяет статистический benchmark. `compileMs` в JSON — время создания общего pipeline на CPU, отдельно от GPU timestamps. Diff чистого материала = 0. Изменение материала не меняет geometry/BVH cache key; смена layout один раз инвалидирует прежний prepared cache.

Исходники и их хэши сохранены в [provenance.json](provenance.json). Повторение: `npm test`, `npm run build`, `npx playwright test tests/browser/surface-wear.spec.ts tests/browser/denoise.spec.ts tests/browser/settings-link.spec.ts` при свободном порте 5173.
